# 08 — Internationalisation

Two locales: **`en`** (source) and **`ro`**. Nothing else. No RTL, no third
language, no machine translation at runtime.

---

## 1. Routes

| Locale | URL | Notes |
|---|---|---|
| `en` | `/` | Default. English at the root — the property is in Romania but the wider audience and the linked-from-abroad case favour English at `/` |
| `ro` | `/ro/` | Trailing slash, canonical |

Both are fully pre-rendered static HTML. **No client-side language swapping of
DOM text** — the switch is a navigation, so that:

- the URL is shareable and bookmarkable,
- search engines index both languages separately,
- no layout shift or flash of the wrong language on load.

`MUST NOT` use `?lang=ro` or a cookie as the primary mechanism.

## 2. Switch behaviour

**Placement.** Top-right of the header, always visible, on every breakpoint and
in every header state. This is a requirement, not a preference: the design is
minimal and the header can look empty, and the switch is the one piece of utility
that must never hide.

**Markup.**

```html
<nav aria-label="Language / Limba">
  <a href="/" hreflang="en" lang="en" aria-current="page">EN</a>
  <span aria-hidden="true">/</span>
  <a href="/ro/" hreflang="ro" lang="ro">RO</a>
</nav>
```

**Behaviour.**

1. The switch is a real `<a>` with a real `href` to the *equivalent* page in the
   other locale. It works with JavaScript disabled and it is crawlable.
2. On click, the current scroll anchor is preserved: `#rooms` → `/ro/#rooms`.
3. The chosen locale is written to `localStorage["lavanda.lang"]`.
4. **No automatic redirect.** A visitor from Romania who lands on `/` is not
   bounced to `/ro/`. Reasons: a redirect breaks deep links, confuses bots, and
   is wrong for a Romanian-speaking visitor who prefers the English page.
5. `MAY` show a one-line, dismissible suggestion at the bottom of the hero when
   `navigator.language` starts with `ro` and no stored preference exists:
   `Această pagină este disponibilă și în română →`.
   `[CONFIRM]` — recommended only if the owner wants it; it is one more component.
   Never render it above the fold, never as a modal.

**Visual.** Two text links, `label` typography, `--muted-strong` inactive,
`--ink` + 1px underline for the active one, separated by a `/` in `--line-strong`.
Never a `<select>`, never a flag icon (a flag is a country, not a language).

## 3. Document metadata per locale

```html
<html lang="en">          <!-- or lang="ro" -->
```

```html
<link rel="canonical" href="https://example.ro/ro/">
<link rel="alternate" hreflang="en" href="https://example.ro/">
<link rel="alternate" hreflang="ro" href="https://example.ro/ro/">
<link rel="alternate" hreflang="x-default" href="https://example.ro/">
```

- `x-default` → English.
- `<title>` and `<meta name="description">` differ per locale (see 07 §1).
- OG/Twitter cards are per-locale; `og:locale` = `en_GB` / `ro_RO`.
- `<meta property="og:locale:alternate">` points at the other one.

## 4. Content model

```
src/i18n/
  en.json
  ro.json
  index.ts
```

```ts
// src/i18n/index.ts
import en from './en.json';
import ro from './ro.json';

export const locales = ['en', 'ro'] as const;
export type Locale = (typeof locales)[number];

type Dict = typeof en;               // en.json defines the schema
const dicts: Record<Locale, Dict> = { en, ro };   // ro.json: type error if keys drift
```

- **`en.json` is the schema.** `ro.json` is typed against it, so a missing or
  extra key is a **build error**, not a runtime fallback. No silent fallback to
  English — a half-translated Romanian page is worse than a build that fails.
- Keys are dot-namespaced and match §07 exactly: `hero.line`,
  `room.family-suite.desc`, `itinerary.slow-day.beat.3`.
- Values are strings, or arrays of strings where order matters (itinerary beats).
- Interpolation uses `{name}` placeholders, replaced at build time. No `eval`,
  no template library.
- Room data (prices, unit counts) lives in `src/data/rooms.ts`, **not** in the
  dictionaries — numbers are locale-independent.

## 5. Romanian specifics

### 5.1 Diacritics

Use **comma-below** forms, never cedilla:

| Correct | Wrong | Codepoint |
|---|---|---|
| ș | ş | U+0219 / U+015F |
| ț | ţ | U+021B / U+0163 |
| ă | — | U+0103 |
| î | — | U+00EE |
| â | — | U+00E2 |

A build-time lint `MUST` fail on `ş` and `ţ` (U+015F, U+0163). This is the single
most common Romanian typography error and it looks wrong to every Romanian reader.

### 5.2 Plurals

Romanian has **three** CLDR categories — `one`, `few`, `other` — and `other`
inserts the particle **`de`**:

| n | Romanian | Category |
|---|---|---|
| 1 | 1 cameră | one |
| 2 | 2 camere | few |
| 19 | 19 camere | few |
| 20 | 20 de camere | other |

Use `Intl.PluralRules('ro')` and message objects, never string concatenation:

```json
"rooms.count": {
  "one":  "{n} cameră",
  "few":  "{n} camere",
  "other": "{n} de camere"
}
```

English is `one` / `other` only. **The `de` particle is the thing a translator
service will get wrong** — it is called out here so it is not missed.

In practice only small numbers appear (`1 room of this type`,
`2 rooms of this type`, `3 rooms of this type`), so the `other` branch is
defensive, not decorative.

### 5.3 Numbers and units

- Prices: `350 lei` — no thousands separator needed at this range, but if a total
  ever appears use `1.250 lei` (`Intl.NumberFormat('ro-RO')`).
- Elevation: `1.904 m` in Romanian, `1,904 m` in English.
- Distances: `9 km`, `40 km` — same in both.
- Drive times: `55 min`, `1 h`, `1 h 15` — never `1,25 h`, never `75 min`.
- Dates: not used. If one is ever added, `Intl.DateTimeFormat` with `ro-RO` and
  `en-GB` (not `en-US` — this is Europe, day-first).

### 5.4 Quotation marks

- English: `"…"` (U+201C / U+201D)
- Romanian: `„…"` (U+201E / U+201D)

Only matters if a quote is ever added. There are none in v1.

### 5.5 Length and layout

Romanian runs **+10–18%** longer than English. Test rules:

- No container is sized to an English string's width.
- Buttons use padding, never `width`.
- The header nav must be checked with `Împrejurimi` (the longest RO nav item) at
  every breakpoint.
- The rates rows must not wrap the price onto a second line in RO.
- Romanian `Vezi toate cele 5 fotografii` is ~30% longer than `See all 5 photos`.

## 6. What is *not* translated

- The property name: `Pensiunea Lavanda` in both locales.
- Place names in the English copy stay Romanian proper nouns: `Ceahlău`,
  `Bicaz`, `Neamț`, `Piatra Neamț`, `Târgu Neamț`, `Durău`, `Văratec`, `Agapia`.
- The English gloss is given once, on first mention: `Neamț Monastery`,
  `Bicaz gorges`, `Red Lake`.
- Prices and units.
- Alt text **is** translated — and authored, never machine-translated (§07.12).
